# Administration: Kontaktpositionen

In diesem Bereich pflegst du Positionsbezeichnungen für Ansprechpersonen.

## Beispiele für Positionen

- Vorstand
- Trainer
- Abteilungsleitung
- Jugendleitung

## Funktionen

- neue Position anlegen
- Position umbenennen
- Position löschen

Diese Positionen stehen danach in Vereins- und Abteilungszuordnungen zur Auswahl.
