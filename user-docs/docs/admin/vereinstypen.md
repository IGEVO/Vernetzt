# Administration: Vereinstypen

Hier verwaltest du die Stammliste der Vereinstypen in **Vernetzt**.

## Typische Aufgaben

- neuen Vereinstyp anlegen
- bestehenden Vereinstyp bearbeiten
- Vereinstyp löschen

## Warum ist das wichtig?

Vereinstypen helfen dabei, Vereine einheitlich zu kategorisieren und später leichter zu filtern.

::: callout tip "Konsistente Benennung"
Nutze klare, einheitliche Bezeichnungen (z. B. „Sportverein“, „Förderverein“), damit Auswertungen sauber bleiben.
:::
