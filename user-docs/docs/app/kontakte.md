# Kontakte

In **Kontakte** suchst du Personen zentral über alle für dich sichtbaren Vereine, Abteilungen und Gruppen.

## Suche

Du kannst nach folgenden Kriterien suchen:

- Name
- Verein
- Abteilung oder Gruppe
- Position

## Was eine Kontaktkarte zeigt

Je nach Sichtbarkeit und Zuordnung:

- Name
- E-Mail
- Telefonnummer
- Zugehörige Vereine, Abteilungen und Gruppen
- Positionen
- ggf. abweichende Zuordnungs-E-Mail

## Direktnavigation

Von der Kontaktkarte gelangst du direkt zu:

- Vereinsdetails
- Abteilungsdetails

::: callout tip "Amtsadressen erkennen"
Ist bei einer Zuordnung eine bestätigte Amtsadresse hinterlegt (z. B. vorstand@verein.de), wird sie statt der persönlichen Adresse angezeigt. So siehst du schnell, welche Adresse für genau diese Rolle gilt.
:::
