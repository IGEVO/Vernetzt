# Navigation und Bedienung

## Obere Leiste in Vernetzt

In der oberen Leiste von Vernetzt findest du:

- Menü-Schaltfläche (öffnet/schließt Navigation)
- Vernetzt-Logo
- Hilfe-Symbol (öffnet diese Dokumentation)
- Hell/Dunkel-Schalter
- Benutzer-Menü mit deinem Profilbild (Mein Konto, Abmelden)

## Benutzer-Menü rechts oben

Über dein Benutzer-Menü erreichst du direkt:

- **Mein Konto** – mit den Bereichen Profil, Zuordnungen, Anmeldung & Sicherheit und Datenschutz
- **Abmelden**

So kommst du jederzeit schnell an deine persönlichen Funktionen.

## Seitennavigation

Die linke Navigation führt dich zu:

- Dashboard
- Vereine
- Kontakte
- E-Mail versenden
- Administration (rollenabhängig)

## Rollenabhängige Menüs

Je nach Rolle siehst du unterschiedliche Einträge. Wenn dir ein Menüpunkt fehlt, hast du dort wahrscheinlich keine Berechtigung.

## Mobilgeräte

Auf kleineren Bildschirmen ist die Navigation kompakter und kann temporär eingeblendet werden.

::: callout tip "Schneller arbeiten"
Nutze das Dashboard als Startpunkt und springe von dort direkt in die häufig genutzten Bereiche.
:::
