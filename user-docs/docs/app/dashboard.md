# Dashboard

Das **Dashboard** ist deine Startseite in Vernetzt.

## Was du hier siehst

- eine persönliche Begrüßung
- deine Vereine und zugehörigen Abteilungen und Gruppen
- Schnellzugriffe auf häufige Funktionen

## Schnellzugriff-Karten

Je nach Berechtigung findest du hier z. B.:

- **Vereine**
- **Kontakte**
- **Mein Konto**
- **E-Mail versenden**
- **Benutzerverwaltung** (nur mit entsprechender Rolle)
- **Administration**-Funktionen (rollenabhängig)

## Meine Vereine, Abteilungen & Gruppen

Wenn du Vereinen oder Abteilungen und Gruppen zugeordnet bist, kannst du direkt klicken auf:

- Vereinsdetails
- Abteilungsdetails

Das spart dir den Umweg über die Listenansicht.

::: callout tip "Empfehlung"
Wenn du regelmäßig E-Mails an Gruppen versendest, starte direkt vom Dashboard über **E-Mail versenden**.
:::
